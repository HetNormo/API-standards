### EDA-R-08: Consumers acknowledge messages only after successful processing

| Strategy | Consumers acknowledge messages only after successful processing. |

#### Description

Consumers must send acknowledgments to the broker only after successful processing of the received event. This ensures reliable message delivery and prevents data loss. Consumers must operate in manual (client) acknowledgment mode (autoAck = false in AMQP), where the consumer explicitly confirms message completion.

If a consumer fails or crashes before sending the acknowledgment, the broker will re-deliver the message according to the at-least-once delivery model.

#### Implication

*	Consumers must use manual acknowledgment mode (autoAck=false)
*	Acknowledge messages only after all processing and downstream updates complete successfully.
*	Failed messages should be retried with exponential backoff and moved to a DLQ after retry exhaustion.

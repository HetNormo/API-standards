### EDA-R-05: AsyncAPI is used for documenting message channels

| Strategy | Queues have a defined expiration period. |

<details><summary>

Open section for explanation, rationale and exception conditions 

</summary>

#### Description

All AMQP message channels (queues, exchanges, topics) and their associated events should be documented using the [AsyncAPI specification](https://www.asyncapi.com/en). This ensures consistent, machine-readable documentation of event-driven interfaces, enabling better discoverability, interoperability, and maintainability across systems.

#### Label

SHOULD

#### Rationale

*	EDA-P-06
*	EDA-P-11
*	EDA-P-12

#### Implication

*	Development teams create and maintain AsyncAPI specifications alongside AMQP queue implementations.
*	Any changes to queue structure or event payloads require corresponding updates in the AsyncAPI documentation to maintain consistency.
